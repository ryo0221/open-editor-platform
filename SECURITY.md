# Security Policy — Preview

This project is preparing an AGPLv3 Preview release. It is not a managed service and does not promise security maintenance, fixed response times, a vulnerability bounty, guaranteed patches, uptime or enterprise support.

## Reporting potential vulnerabilities

Please avoid posting exploit instructions, secret material, personal data or unpatched high-severity findings in public Issues. Use **GitHub private vulnerability reporting if enabled for this repository**. Otherwise use a private maintainer contact channel listed on the repository owner's profile. If no private contact method is available, do not disclose sensitive exploit details publicly; report only non-sensitive context until a secure channel exists.

Please include affected version/commit, reproducible steps, potential impact and minimal non-sensitive evidence. The maintainer may triage findings and publish fixes when able; no SLA is offered.

## Scope and limitations

Source-code publication is not a promise that arbitrary downloaded or independently authored Editor plugins are safe. Do not execute untrusted plugin code in a privileged Host context. The reference collaboration Host is not a production authorization or durable hosting service. Users and commercial licensees are responsible for securing their deployments and dependency update policies.

See [known limitations](docs/status.md) and [OSS Preview release gate](docs/release/OSS-PREVIEW-GATE.md).
