# geometry-core (domain-independent geometry, R2c)

Private package of the R2c design (`geometry-core`): what CAD and the building domain share without depending on each other. Not a registered editor or a stable public API. No dependency.

- `p21.ts`: the ISO 10303-21 value model (`P21Value`) and `readP21(bytes, limits)`, a schema-free reader. It decodes UTF-8 (else Latin-1), comments, every value form (references, enumerations, reals, integers, strings with `\X\`, `\X2\`, `\X4\`, `\S\` and `\P?\` directives, binaries, typed values, lists, `$`, `*`) and complex instances, and returns header entities and instances by ID. It refuses rather than repairs (`p21-syntax` with the line, `p21-duplicate-id`, `p21-unresolved-reference`) and enforces byte, instance and nesting limits while reading (`p21-too-large`, `p21-too-many-entities`, `p21-too-deep`).

The IFC import (`bim-ifc`) reads with it since R2c-4b, and the STEP import's scan (`cad-kernel-occt`) since R2c-1 (`references: 'keep'`: the scan leaves resolving to the kernel's reader). - `ops.ts` (R2c-1b): geometry ops, the domain-independent recipe of a shape as a graph of nodes by ID: `prism` (outer loop and holes with arcs by bulge in a plane frame, swept along a vector; a straight profile sweep is a prism whose vector need not be the normal), `boolean` (cut, union, common of a target and tools), `halfSpace` (keep one side of a plane), `transform` (rigid placement), `brep` (a normalized BRep asset) and `compound` (several shapes kept apart, so a drawing projects them together and one hides another; R2c-5). `validateGeometry(graph, requests)` returns issues by node and path (missing nodes, cycles, loops, frames, vectors in the plane, rotations, limits, requests it cannot answer); `geometryNodeKey` is a canonical key of a node and everything it reads, for caches. Requests ask a node for a `mesh`, a `measure`, an exact `section` by a plane or a `projection` (visible and hidden edges).

- `fixtures.ts`: F30, one small graph per op with its analytic values (`f30Fixtures`).
