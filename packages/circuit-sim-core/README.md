# circuit-sim-core (SL4, DC circuit calculation)

Private pure TypeScript circuit calculation for the circuit domain of the circuit simulation plan and ADR 021 (addendum). No DOM, React or Worker; it reads `schematic-core` and no other domain.

- `schematicCircuit(doc)`: the circuit a schematic makes. One node per net, every ground net as node 0 (`no-ground` when there is none), one element per part with a `model` (others listed in `left` as `no-model` or `model-terminal`), and an ideal source from ground for each net in use that a rail power port whose name reads as a voltage (`3V3`, `5V`, `1V8`, `+12V`) names, found through the net's names (`rail-conflict` when two voltages meet on one net or a voltage rail is on ground; the source's ID is `rail:<name>`, suffixed `#2` when a part has that ID). Initial safety limits `circuitLimits` (`limit-nodes`, `limit-elements`) are not performance promises.
- `circuitDcOperatingPoint(circuit, options)`: modified nodal analysis with a dense matrix (Gaussian elimination, partial pivoting). Resistor, capacitor (open), inductor (short), voltage and current sources, switch (a resistor; closed when listed in `switches`), diode (Shockley with gmin), LED (a diode with emission 2 and a saturation current per colour, `circuitLedModels`), BJT (Ebers–Moll transport, βR = 1) and MOSFET (level 1, drain and source swap). Newton–Raphson with SPICE's junction limiting; when it does not converge, source stepping in tenths. `drives` are GPIO pins: an output is a voltage behind a resistance, an input a pull resistor and a threshold read back in `inputs`. Refused as `CircuitError`: `net-name-duplicate` (two nets in use with one name), `floating-node` (no DC path to ground, a MOSFET gate being none; checked before solving), `dc-singular`, `dc-no-convergence` (with the worst node).
- Results: node voltages by net name, and per element the current into each terminal.
- `circuitDcSweep(circuit, source, values)`: one source's volts or amps stepped, each point started from the one before.
- `circuitTransient(circuit, { stop, maxStep, method, events, switches, drives })` (SL5a): from the DC operating point, capacitors and inductors as trapezoidal (or backward-Euler) companions, the step set by a local error estimate (corrector against a linear predictor), landing on every event time (a switch or a GPIO output changing) and restarting after it with Euler steps checked by step doubling. Nodes only capacitors hold start from a tiny conductance to ground. Refused: `tran-stop`, `tran-step`, `tran-tolerance`, `tran-event`, `tran-step-too-small`, `limit-steps`, `floating-node`. `circuitTranCsv` writes chosen waveforms.
- `circuitTransientStepper(circuit, options)` (SL8a): the same transient advanced piece by piece (`advanceTo`), with switches and GPIO outputs changed between pieces (`change`, restarting with Euler steps as after an event) and the input drives read at the time reached (`inputs`). `circuitTransient` is this stepper run to `stop`.
- `circuitSpice(circuit, { switches, drives })`: a SPICE `.cir` netlist (`.model` lines with one name per parameter set, GPIO drives as sources and resistors, `.op`) to check a result elsewhere.

Not yet here: the screens and the Worker (SL5b), the ladder and co-simulation (SL6–SL8). See the verification record.
