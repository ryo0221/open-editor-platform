# geometry-kernel-occt (domain-independent OCCT kernel, R2c)

Private package of the R2c design and ADR 017: the parts of an OCCT (OpenCascade.js) kernel adapter that no domain owns. CAD (`cad-kernel-occt`) uses it today; the building domain (`bim`) will use it without depending on CAD. Not a registered editor or a stable public API. Depends on `geometry-core` only.

- `build.ts`: `KernelBuild` (module URL, Wasm URL, `sha256:` build hash) and `loadKernelBuild(build, marks)`, which refuses Wasm bytes with another hash, then compiles and instantiates them as separate steps, marking each phase in the performance timeline. `kernelLoadMarksOf(prefix)` names a domain's marks (`<prefix>:load-start` … `<prefix>:instantiated`).
- `module.ts`: `OcModule` (the untyped Embind surface) and `decodeKernelException`, which reads an OCCT exception thrown through Embind as its type and message and frees it when the build can.
- `catalog.ts`: `KernelCatalog` (current, retained, revoked builds and approved substitutes) and `resolveKernelBuild`: exact, a reference display by an approved substitute of the same semantics version, or unavailable/revoked.
- `jobs.ts`: `createKernelJobs`, the Worker side's job order (one at a time, in arrival order) and cancels: a job cancelled before it starts is refused, a running one checks at its own cancel points (`KernelJobCancelled`).
- `mesh.ts`: `vertexNormals`, per-node normals of a triangle mesh.
- `ops.ts` (R2c-1b): `evaluateGeometry(oc, graph, requests, options)` runs a `geometry-core` op graph after validating it: `BRepPrimAPI_MakePrism` of a planar face (arcs from `gp_Circ`), the Boolean algorithms with several tools at once, `BRepPrimAPI_MakeHalfSpace` with `BRepAlgoAPI_Common`, `BRepBuilderAPI_Transform`, `BRepTools::Read` and a `TopoDS_Compound` (R2c-5). Each node is built once per call and must give a valid shape with a solid (`invalid-shape`, `empty-result`); a failed node fails the requests that read it, naming that node. Answers: a mesh at the request's deflection, volume, area and bounds, the exact plane section (`BRepAlgoAPI_Section`) as polylines (circles in 128 chords per turn), and visible and hidden edges of a mesh along a view direction (`HLRBRep_PolyAlgo`, R2c-U7) as segments in the view plane. `ops.test.ts` runs F30 against the development build.

Domain-specific evaluation (features, naming, topology tables, pick ids) stays in the domain's adapter. `geometry-kernel.test.ts` also checks that no `bim-*` or `geometry-*` package depends on or imports a CAD package; ESLint enforces the same.
