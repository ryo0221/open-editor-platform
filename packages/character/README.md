# character (Character C1c, Surface)

Experimental React Surface for the [Character design](../../docs/character/README.md) and ADR 019. Registered in the Playground; not a stable public API. No CAD or BIM imports (ESLint).

- `CharacterSurface`: the C1 viewer. The Host passes an `EditorSession<CharacterDocument>` and the asset bytes by asset ID; the Surface checks every asset against the document (`readCharacterAssets`: present, same length and SHA-256, EPM decodes, meshes match) and draws nothing when one does not match. It plays an action (play, pause, stop, seek by slider, arrows by one frame, Page keys by one second, Space to play or pause, loop), shows or hides parts as one EditorSession edit with Undo, and shows the model's counts, the Host's import report (losses) and VRM terms of use. The transport sits under the view at every width. Optional `onImport(file)` offers "Import glTF or VRM"; the Host reads the file (`importGltf`) and replaces the session.
- `frame.ts`: `characterFrame(doc, meshes, action, tick)` poses every part on the CPU with `character-core`'s `poseAt`, `worldMatrices` and `skinMatrices` (morphs, then linear blend skinning with every weight, or the part's world matrix), per display corner with normals. GPU skinning is later.
- `playback.ts`: the transport as pure state (`advance`, `play`, `pause`, `stop`, `seek`, `choose`); the playhead is view state and never enters the document or its history.
- `viewport.ts`: `CharacterViewport` (Three.js, Z up, millimetres): one mesh per part with its material slots and colour maps (decoded flipped, UV v up), orbit, a grid fitted to the figure.
- `test-host/`: a standalone host (`npx vite --config packages/character/vite.config.ts`, port 4205) with F-C1, `?readonly=1` and `?broken=1`; browser tests run with `E2E_SUITE=character npx playwright test`.
- C3e mesh edit mode (`mesh-edit.ts`, `mesh-inspector.tsx`, `mesh-overlay.ts`): with the Host's `onMeshAsset({ ref, bytes })` (it keeps the bytes, saved, before the content names them), the Parts panel offers "Add cube" and each part can be chosen; its Inspector offers "Edit mesh" and "Remove part". Edit mode draws the part at rest with its cage on top (X-ray), selects vertices, edges or faces by click (Shift adds; `pickElement` counts hidden elements, the nearer wins), and runs Move, Extrude, Inset, Delete faces, Loop cut, Bevel, Set crease and Merge, with "Mirror across X". Each operation is one edit that swaps the part's mesh asset (`characterMeshEdit`); the edit applies only to the document it was made from, the extruded caps or inset faces stay selected, and the Undo history's asset bytes are kept within `characterLimits.historyAssetBytes`. Subdivision levels are part settings; a part with levels is drawn from `subdivideMesh` of its cage (cached per cage and level). A mesh edit keeps the camera. Test host: `?empty=1`, `?edit=1` (`slow`, `refuse`).
