# Contributor rights — dual AGPL/commercial project

All contributors retain ownership of their original eligible contributions. The project intends to accept contributions under AGPLv3 for the public release and also to offer alternative commercial/OEM licenses for authorized code.

Because contributors retain their copyrights, **a PR alone does not grant the project the rights necessary to relicense contributions to proprietary customers**.

Before any code PR is merged, the project must collect and preserve a signed Contributor License Agreement or another adequately documented permission granting rights to publish under AGPLv3 and to sublicense the contribution under negotiated commercial terms, plus appropriate contributor patent permissions. The draft form in [legal/CONTRIBUTOR-AGREEMENT-DRAFT.md](legal/CONTRIBUTOR-AGREEMENT-DRAFT.md) is not an agreement until properly signed and accepted.

Contributor employers, third-party code, generative-AI provenance, license notice obligations and compatibility must be checked. The maintainer may reject a PR for technical, security, licensing or maintenance reasons. **Users do not have to submit a PR to use their own extension privately or under any otherwise available lawful permissions.**

Any independent Editor exception must be approved and expressly granted by all copyright holders for the code to which it applies; it is not silently created by this contributor policy.
