# スライドの動きと書き出し、文書からスライド

設計版 1、2026-11-23。既存 Slide Editor（`packages/slide`・`packages/slide-export`）への能力追加。新しい kind は作らない。
この PR は決めることを示すだけで、実装は後の PR で出す。

## 目的

新規事業計画の説明資料のように、論点を順に見せるデッキを作り、そのまま発表・動画・配布資料・PowerPoint に使えるようにする。

- オブジェクトごとの登場・退場・強調と、出す順（クリックごと・前と一緒・前のあと）、遅れ・長さ。
- ページの切り替え（フェード・押し出し）。
- 発表でクリック・矢印キーにより段ごとに進む・戻る。
- 書き出し：MP4（段ごとの待ち時間で自動再生）、PDF（最後の姿／段ごとにページを分ける）、PPTX（PowerPoint で同じ順に再生される）。
- 文書（Document の文書 JSON）から、見出しごとにスライドを作る。新しいデッキか、今のデッキの末尾へ足す。
- 生きた引用（値・図）を含むスライドでも、動き・発表・書き出しが働く。

いまの発表はページ単位で進み、埋め込み Animation はコンポジションを再生するだけで、オブジェクト単位の段や切り替えをデッキが持たない。表示の切り替えでは足りないため、デッキの形式に足す。

## データ形式（Slide content schema 3）

`draft.content`・`versions[].content` の中だけを変える。外枠と保存版レコードの `schemaVersion` は 1 のまま。v1・v2 はそのまま読み、動き・切り替えは空、書き出しの設定は既定として扱う。動きや設定を初めて保存する変更で下書きだけを v3 にする（Undo で旧版の下書きに戻る）。保存済みの版とハッシュは変えない。

| 欄                            | 内容                                                                                                                                                                                                                                                                                      |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `slides[].steps[]`            | クリックで進む段。各段に `id` と 1 件以上の `effects`。配列順に進む。                                                                                                                                                                                                                     |
| `slides[].steps[].effects[]`  | `id`・`targetId`・`phase`（enter／exit／emphasis）・`effect`（enter：fade・slide-in・zoom、exit：fade・slide-out・zoom、emphasis：zoom）、slide-in／out だけ `direction`。`trigger`（段の先頭は on-click、後続は with-previous／after-previous）、`delayMs`・`durationMs`（整数ミリ秒）。 |
| `slides[].transition`         | このページに入るときの切り替え。`kind` は none・fade・push。fade／push は `durationMs`、push は `direction`。                                                                                                                                                                             |
| `exportSettings.mp4`          | `defaultHoldSeconds`（既定 1 秒）と、ページの初期状態または段の完了状態ごとの `holds[]`。                                                                                                                                                                                                 |
| `exportSettings.pdf.pageMode` | final（最後の姿 1 枚、既定）か steps（初期状態と各段の完了を 1 枚ずつ）。                                                                                                                                                                                                                 |

決まり：

- ID は `step_`・`effect_` と UUID v4。並べ替え・Undo・Redo で保ち、削除した ID を別の要素に使わない。複製では新しい ID を出し、複製の中の参照を張り替える。
- 一段で同じ対象への効果は 1 つまで。対象は同じページのグループ以外のオブジェクト。最初の指定が登場なら初期は非表示。
- 対象を消すと、その対象への効果も同じ更新で消す。空になった段とその待ち時間も消し、先頭が消えた段は次の効果を on-click にする。Undo で一緒に戻る。
- 上限：ページあたり 100 段・100 効果、デッキで 1,000 効果。遅れ 0〜10,000 ms、長さ 1〜10,000 ms、切り替え 1〜3,000 ms、待ち時間 0〜60 秒。
- 発表中のページ・段・再生時刻、書き出しの進み具合は保存しない。

## 操作

既存の `EditorCommand<SlideContent>` と同じ形で、人の編集と Host の提案（AI の作業役の案を人が採用する）が同じコマンドと検証を通る。

| 操作                                           | Undo の単位                           |
| ---------------------------------------------- | ------------------------------------- |
| 段の追加・削除・並べ替え                       | 1 操作                                |
| 効果の追加・値の変更・削除・段の間の移動       | 1 操作（開始関係の付け直しを含む）    |
| 切り替えの設定・解除                           | 1 操作                                |
| MP4 の既定・状態別の待ち時間、PDF のページ分け | 1 操作                                |
| 効果と切り替えのまとめた編集（提案向け）       | まとめて 1 操作                       |
| 文書から新しいデッキを作る                     | Host が一括で作る                     |
| 文書から今のデッキの末尾へ足す                 | 全ページを 1 操作                     |
| ページ・オブジェクトの削除と複製               | 関連する動きと待ち時間を含めて 1 操作 |

拒否（対象が無い、上限を超える、開始関係の不整合、読み取り専用）では、内容と Undo・Redo 履歴を変えない。発表と書き出しは編集コマンドを出さない。

## 画面

![動きの設定](slide-motion/slide-motion.svg)

- インスペクターに「動き」：段の一覧、効果の対象・用途・種類・きっかけ・遅れ・長さ、ページの切り替え。
- 発表：クリック・→・Space で進み、←で戻る。戻るとその段の姿に戻る。タッチは左右のタップ。
- 書き出しの窓：MP4 の待ち時間と見積もり（秒・フレーム）、PDF のページ分けとページ数、PPTX の事前確認。
- 文書から作る窓：文書の選択、新しいデッキ／末尾に足す、変換の下見と拒否の理由。
- 狭い画面ではインスペクターを下の引き出しにする。IME の確定前は Enter で適用しない。読み取り専用では動きの欄を読むだけにする。

## 書き出し

段ごとの表示状態（あるページの段 n の時点で各オブジェクトが見えるか、動きの途中の姿）を 1 つの関数で求め、発表・PDF・MP4・PPTX が共有する。

- **PDF**：既存の `exportSlides`（SVG → ページ）に、段ごとの静止状態を渡す。上限 500 ページ。
- **MP4**：段ごとの時間からフレームを描き、既存の H.264 ライター（`@editor-platform/character/video` の `encodeMp4`）で包む。30 fps、最大 1920×1080、18,000 フレーム、1 GiB。符号化できない環境では理由を出して止める。
- **PPTX**：既存の `slide-export` の計画と pptxgenjs の出力に、各スライドの `p:timing`（クリックごとの段、with／after、遅れ・長さ）と `p:transition` を足す。形式で決めた効果はすべて PowerPoint の効果（フェード・フライイン／アウト・ズーム、強調の拡大／縮小、切り替えのフェード・プッシュ）に対応させる。PowerPoint で同じに再生できないもの（埋め込み Animation の再生など）は事前確認で示し、書き出さない。
- 失敗したら完成ファイルを渡さない。

## 生きた引用

- 書き出しは、デッキが持つ固定版の値・図をそのまま焼き込み、引用元と版の注記を付ける。引用元に新しい版があっても書き出しは変えない。必要な固定版の図が解決できなければ止める。
- 発表と書き出しでは「引用」の字と色の帯を描かず、値・図だけを描く（編集画面の目印はそのまま）。
- 値の桁区切り・単位の繰り上げはこの変更で扱わない（別の変更にする）。

## 文書からスライド

- Document の検証を通した文書（版 1・2）を使う。非表示のブロックは飛ばす。
- 表示される見出し 1 つにつき 1 ページ。見出しが題、次の見出しまでの段落・箇条書き（番号・チェックを含む）を順に本文にする。値の引用は `liveQuote` を持つテキスト、図の引用は `liveQuote` を持つ画像として、引用元と固定版を保つ。生成したページに動きと切り替えは付けない。
- 不正な文書、見出しが無い、最初の見出しより前に内容がある、変換できないブロックがある、上限（入力 8 MiB・2,000 ブロック、生成 100 ページ・各 100 オブジェクト）を超える場合は、場所と理由を出して全体を断る。部分的には足さない。

## 扱わないこと

モーションパス、音・ナレーション、3D の切り替え、PowerPoint の全効果、PPTX の動きの取り込み、埋め込み Animation 自体の動画化、値の書式の拡張、文書のレイアウトの再現、動きの操作の共同編集。
