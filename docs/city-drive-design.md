# PLATEAUの街を車で走る動画の計画

PLATEAU（国土交通省の3D都市モデル）の建物・道路・橋を、キャラクターのscene（[Characterの設計](character/README.md)）に背景として読み込み、CADで作った車（「翔」、F149）を道路に沿って走らせ、cameraを付けて動画に書き出せるようにする計画。**2026-11-18に作成。計画のみで未実装。決定事項（CD-U1〜U7）は未決で、実装の開始はオーナーの判断を待つ。** 既存のdomainの決定と受け入れ条件は変えない。性能に関する記述はすべて上限の提案で、測定ではない。

## 先に作った動画（エディタの外）

2026-11-18、エディタを変えずに、three.js 0.186.1と`3d-tiles-renderer` 0.5.4でPLATEAUの3D Tilesと「翔」のGLB（CL9の完成形をkernelで書き出したもの）を読み、場面ごとに経路・車線・cameraを決めて1コマずつ描いた。場面は(1)丸の内駅舎の前、(2)中央通りを京橋から銀座4丁目へ、(3)レインボーブリッジを芝浦から台場へ。生成のsourceと動画はリポジトリの外に置き、Gitには入れない。

このとき分かったことが、エディタへ足すものの要件になる。

| 分かったこと                                                                                                                                                                                              | エディタで要ること                                                         |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 2025年度版の千代田区・中央区・港区には、写真のtexture付きの建物（LOD2）、道路の面（LOD3、車道部・歩道部の区別つき）、橋（LOD2、レインボーブリッジの吊り材まで）がある。地形（地面の高さ）の3D Tilesは無い | 建物・道路・橋を読み、地面は道路の高さの平面で補う                         |
| 高さは楕円体高（例：銀座の道路約40.4 m、レインボーブリッジの上の路面約101 m、海面約36.6 m）                                                                                                               | 経路の原点を緯度・経度・楕円体高で決め、局所の東・北・上（mm）に直す       |
| texture付きのLOD2は大きい（中央区だけで345 MB）。全部を読むと描画の記憶域が足りず、街が欠ける                                                                                                             | 使う範囲だけを切り出して保存し、描画の予算を決めて越えたら知らせる         |
| 道路のモデルに車線・白線は無い                                                                                                                                                                            | 車線のずれ（左側通行）を指定し、白線は経路に沿って描く（作ったものと明示） |
| 車を道路に載せるには、道路の面の高さを経路に沿って測る必要がある。カメラの近くだけ詳しいタイルを読むと、遠くの経路の高さが取れない                                                                        | 上から見た全体の読み込みで、経路の高さを先に測って保存する                 |
| 出典の表示が要る                                                                                                                                                                                          | 書き出す動画に出典を焼き込む                                               |

## 小段階

| 小段階 | 内容                                                                                                                                                                                                                                                                                                         | 依存     |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- |
| CD1    | 都市モデルの切り出しと保存：PLATEAUのカタログ（データセットの一覧）から区・種類（建物・道路・橋）・LODを選び、緯度・経度の範囲で必要なタイルだけを取り、出典（URL・年度・データセットID）とタイルごとのhashのmanifestと一緒にprojectの資産として保存する。保存した切り出しは読み取り専用で、内容のhashで指す | なし     |
| CD2    | sceneに置く：キャラクターのsceneに都市モデルのprop（`{ kind: 'city', assetId, contentHash, origin: { lat, lon, height } }`）を足し、原点を局所の東・北・上（mm）に直して描く。地面は道路の高さの平面。描画の予算（タイルの数・bytes）を越えたら断る。Undo/Redo・保存・再読込                                 | CD1      |
| CD3    | 道路に沿って走る：道路の上に点を打って経路を作り（道路の帯の中心へ寄せる補助つき）、車線のずれ・速さ・開始を決めると、車のpropの位置・向きのkeyと車輪の関節のkeyを生成する。高さは道路（または橋）の面を上から測った値。白線は経路に沿って描く（任意）                                                       | CD2      |
| CD4    | cameraの型：車に対する追走・横を流す・前から・上から（drone）の型を選び、時間の区間ごとにcameraのtrack（CR7e）のkeyを生成する。生成したkeyは普通のkeyとして編集できる                                                                                                                                        | CD3      |
| CD5    | 書き出しと出典：C8の動画の書き出しに、出典の文字を焼き込む設定を足す（都市モデルのpropがあれば既定でon）。受け入れの通しの実行（東京駅・銀座・レインボーブリッジの3場面）                                                                                                                                    | CD2〜CD4 |

## 決定を求める事項

| ID    | 論点               | 選択肢                                                                                                        | 推奨と理由                                                                                                                                  |
| ----- | ------------------ | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| CD-U1 | どこに足すか       | キャラクターのsceneのpropとして／新しいkind `city`                                                            | キャラクターのscene。車（CADの版のprop）・関節のtrack・cameraのtrack・動画の書き出しが既にあり、足すのは背景と走行のkeyの生成だけで済む     |
| CD-U2 | データの置き場     | 切り出して資産として保存（hash付きのmanifest）／再生のたびにPLATEAUから取る／ユーザーが手元に置いたfileを読む | 切り出して保存。同じ文書が同じ見た目になり、ネットにつながらない場でも開ける。PLATEAUの配布元への接続は切り出しの時だけ                     |
| CD-U3 | 3D Tilesの読み込み | `3d-tiles-renderer`（Apache-2.0）を固定の版で依存に足す／自前の読み手                                         | `3d-tiles-renderer`。Draco・b3dm・詳細度の選び方・raycastが揃っていて、先の動画で動いた。第三者の通知を足す                                 |
| CD-U4 | 写真のtexture      | 読む／読まない（形だけ）                                                                                      | 読む。動画の見た目のほとんどが建物の写真のtextureで決まる。そのぶん描画の予算（CD2）を置く                                                  |
| CD-U5 | 車の経路           | PLATEAUの道路の面に沿わせる（車線のずれつき）／自由な曲線だけ                                                 | 道路の面に沿わせる。高さを道路から取り、帯の中心に寄せる補助で、左側通行の車線に置ける。自由な曲線も同じ経路として編集できる                |
| CD-U6 | 白線               | 経路に沿って描く／描かない                                                                                    | 経路に沿って描く。道路のモデルに白線が無く、無いと道路に見えにくい。PLATEAUのデータではないので、出典の表示と画面で「作図した白線」と分ける |
| CD-U7 | 出典の表示         | 動画に焼き込む（既定でon）／説明欄に書くだけ                                                                  | 焼き込む。動画だけが共有されても出典が残る                                                                                                  |

## 範囲

- 扱う：PLATEAUの3D Tiles（b3dm、Draco、texture）の建物・道路・橋の切り出しと表示。緯度・経度・楕円体高から局所の座標への変換。道路の面からの高さの測定と経路。走行と車輪の回転のkeyの生成。cameraの型からのkeyの生成。出典の焼き込み。
- 断る（型付きのerror）：PLATEAUのカタログに無いデータセット、範囲の上限（切り出しは1辺3 km、保存は1 GiB、描画のbytesの予算）の超過、hashの合わないタイル、経路が道路・橋の面の外に出る点（高さが取れない）。
- 範囲外：CityGMLの属性の編集、地形（DEM）、信号・標識・他の車や人、昼夜・天気の変化、PLATEAUの3D Tiles以外の都市モデル（Google Photorealistic 3D Tilesなど）、写真品質（path tracing）の連番。必要になれば別のissueにする。

## 性能

描画の時間は端末とtextureの量で大きく変わる。先の動画（headlessのChromium、software描画）では1コマ数秒から数十秒だった。受け入れでは測定せず、描画の予算で断ることと、書き出しの進み具合と取消で守る。
