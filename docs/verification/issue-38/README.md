## Reproduction and corrections

- A focused test first reproduced map-insertion-order differences in emitted TSX.
  Export now sorts unordered maps; roots, slot children, providers and breakpoints
  retain semantic order. No blind native-save normalization was introduced.
- Empty slots previously produced an empty fragment, suppressing original defaults.
  Both isolated preview and emitted TSX now omit those props. Required minima still
  reject absent content. An initial orphan-node fixture was corrected rather than
  weakening preflight.
- Tooling regressions exposed missing required preview samples and optional callback
  parameters. Generic samples remain examples, not defaults; Host overrides are
  explicit. Optional/rest/default/undefined callback parameters diagnose refusal.
- Semantic differences detect stable-ID edits and exact version/implementation
  changes without mutation. Tests cover omitted versus null values, reordered maps,
  conservative breaking changes and unchanged earlier registrations.
- Output tests cover immutable saved pins, input copying before asynchronous hashes,
  tampering, missing files, wrong source/generator/dependencies, duplicate and unsafe
  paths, corrupt versions and malformed/getter-bearing metadata.
- Initial test setup attempted mutation of frozen data, omitted a remapped preview
  prop, and used a Node TextEncoder without its explicit import; fixtures/setup were
  corrected. These were not relaxed validators.
- Initial browser attempts retained failures: mobile Undo required its overflow menu;
  a cancelled development dependency scan logged `entries.join`; production verification
  initially used the wrong preview port (15 failures/4 passes), then lacked the Design
  output server (1 failure/18 passes). The configuration now serves the expected ports.
  The affected mobile flow and Design case passed after their specific corrections.
  No Vite scanner root-cause fix is claimed.
