# Optional manga layer preset

This is consuming-Host sample code, not a Design domain schema. It creates native
group/image/path/text elements and uses Playground's existing command, input,
permission, revision, history and save boundaries. A default build does not enable
the UI or register `window.playgroundArt`.

Opt in with `VITE_MANGA_EXPERIMENT=1 npm run dev`, or build explicitly
with `VITE_MANGA_EXPERIMENT=1 npx vite build`. The fixed eight roles (schema 1) and named human/animal
parts (schema 2) are this sample's presets. They do not constrain native Design
groups/PNGs. AI execution, credentials and transport remain Host-owned; there is
no default live service. The existing schema-1 mask path is a bounded sample,
not semantic recovery or a universal layer taxonomy.

Artwork quality, production and delivery history belongs to the consuming Host.
No generated artwork is stored here.
