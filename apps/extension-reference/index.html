Extension prototype

Switch bundled fixture packages while keeping this draft and its history. The Host verifies the bundled code against its build-time hashes before loading it, keeps the verified packages in this browser and verifies them again on the next start. These are local fixture packages, not third-party downloads. Switching does not migrate or restore document versions.

Retained packages

Removing deletes the package's kept bytes from this browser. It is refused while the package is needed, and it never changes saved drafts or document versions. Uninstall only closes the Editor and keeps the package.

Document versions

Restoring a document starts a new local edit history. It keeps saved versions and the installed fixture unchanged. Use Save to save the draft, or Save document version to create another version.
