Extension prototype

Switch bundled fixture packages while keeping this draft and its history. The Host verifies the bundled code against its build-time hashes before loading it. These are local fixture packages, not third-party downloads. Switching does not migrate or restore document versions.

Document versions

Restoring a document starts a new local edit history. It keeps saved versions and the installed fixture unchanged. Use Save to save the draft, or Save document version to create another version.
